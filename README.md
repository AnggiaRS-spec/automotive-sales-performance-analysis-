# Automotive Sales Performance Analysis 2025

## Overview
This project presents an interactive Power BI dashboard to analyze automotive sales performance throughout 2025.

## Objectives
- Analyze monthly sales trends.
- Evaluate sales performance by branch and product category.
- Identify the top 5 products by sales.
- Analyze payment methods and transaction status.
- Monitor total sales, transactions, quantity, and completion rate.

## Dashboard Features
- Sales Performance Summary
- Monthly Sales Trends
- Sales by Category
- Sales by Branch
- Top 5 Products by Sales
- Transactions by Payment Type
- Transaction Status Analysis
- Interactive Filters for Period, Branch, Category, Payment Type, and Status
